# CHANGELOG

## Version 1.0.2

* Restaurado el tic mecánico del segundero con un pequeño rebote `OutBack`.
* Corregido el cruce de 59 a 0 mediante un ángulo continuo, sin salto en las doce.
* Agregado `BouncySecondHand.qml` dentro del paquete para mantenerlo autosuficiente.

## Version 1.0.1

* El segundero queda habilitado por defecto en instalaciones nuevas.
* La fuente de tiempo se actualiza cada segundo aunque una configuración antigua no contenga `showSecondHand`.
* Corregida la animación antihoraria para Qt 5.

## Version 1.0.0

* Agregada selección de múltiples fondos de pantalla (Giro Sur Real, Constelación, etc.).
* Animación de agujas refinada (`OutBack`) con resplandor sutil.
* Optimización de rendimiento y estabilización tras suspensión o reanudación.
* Lanzamiento estable 1.0.

## Version 0.2.0

* provide an option for circular highlight layouts
* provide an option to disable border lines in calendar
* disable latte side monochromatic coloring

## Version 0.1

* work perfectly with Latte Parabolic effect
* disable Latte margins in Panel mode
* thickness padding supported for both Latte and Plasma
